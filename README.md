# ТоргПит — главная страница

Клиентское демо, доработанное по референсу и исследованию B2B-сценариев. Первый экран учитывает высоту окна; последующие разделы разделены по задачам и фоновым поверхностям. Публичный адрес GitHub Pages: https://Moriarty32.github.io/torgpit/.

## Запуск

Требуется Node.js 22 или новее. Для просмотра и обычной статической сборки установка зависимостей не нужна. Для повторной оптимизации изображений выполните npm ci, затем node scripts/optimize-images.mjs; sharp используется только для разработки.

```sh
npm run dev
```

Открыть http://localhost:4173. Страница также работает при открытии index.html, но для воспроизводимой проверки рекомендуется локальный сервер.

## Сборка

```sh
npm run check
npm run build
```

Папка dist содержит готовый статический сайт с относительными путями. Её можно публиковать в GitHub Pages или другом статическом хостинге. Основная ветка main содержит исходники и сборку; ветка gh-pages — только содержимое dist для публикации.

## Взаимодействия

Двухуровневая закреплённая шапка: оборудование по назначению, форматы заведений, проектирование и информация для покупателей. На компьютере широкие панели открываются кликом или после 300 мс наведения; ниже 1200 px используется мобильная панель с аккордеонами и постоянной кнопкой обращения. Поиск раскрывается отдельно. Поддерживаются клавиатура, Escape, закрытие снаружи и уменьшенное движение.

Поиск категорий с клавиатурными подсказками, фильтрация направлений, подборка оборудования, критерии выбора, FAQ, скачиваемый инженерный чек-лист и бриф. Подборка и черновик хранятся в sessionStorage текущей вкладки; при недоступности хранилища форма работает в памяти.

Форма не использует сервер: проверяет заполнение и готовит текст запроса. Его можно открыть в почте, скопировать или скачать. Клиент подтверждает отправку в своей почтовой программе, план и спецификацию прикладывает вручную. Согласие не сохраняется и не отмечается автоматически.

## Изображения и шрифт

Сгенерировано 16 самостоятельных изображений встроенным image_gen: 10 предметов и 6 сцен. Исходники — source-images/, точные prompts — source-images/prompts.json и sidecar каждого файла. Они иллюстрируют оборудование и решения, не являются документацией товарных моделей или фотографиями выполненных объектов.

Для интерфейса подготовлены 33 WebP-файла общей массой около 1.89 MiB. Ширины hero 640/1024/1600px, предметов 400/800px, сцен 640/1200px. Используются srcset/sizes, явные размеры, lazy loading и приоритетная загрузка hero. Старый reference.png сохранён в исходниках, но исключён из новой публикации. Манифест — assets/images/manifest.json.

Manrope хранится локально, источник — Google Fonts (SIL Open Font License). Акцент, размеры, адаптивность и анимации описаны в DESIGN.md. Исследование источников анимации: docs/motion-research.md.

## Проверка в браузере

Для адаптации страницы выполнены 111 проверок в scripts/browser-qa-layout.js на 14 размерах окна от 320×740 до 2560×1440, включая невысокие и горизонтальные окна. Проверены геометрия hero, ширина контента, переполнение, читаемость карточек, размеры подписей и областей нажатия, структура секций и внутренние переходы. Исследование — docs/design-audit-v4.md; снимки и результаты — output/playwright/v4/. Реальные устройства отдельно не проверялись.

Результат v4 и границы проверки описаны в docs/verification-v4.md. Дополнительно прошли 11 целевых проверок фотографического фона под текстом и стыка условий/отзывов; вместе с проверками шапки и прежних сценариев — 210 успешных проверок. Финальное визуальное ревью: ship.

После изменения шапки выполнены 49 проверок в scripts/browser-qa-header.js: переходы и подбор, поиск, условия и скачивание, клик и задержка наведения, закрытие и фокус, мобильная модальность, смена ширины, fallback без JavaScript и размеры 320–1440 px. Повторно пройдены 39 проверок прежних сценариев из scripts/browser-qa-v2.js, включая сохранение текста, подборку, запрос, отказ Clipboard API и скачивания. Скрипты — функции для Playwright CLI run-code с аргументом page. Отчёты и снимки шапки — output/playwright/header-*, основные снимки ревью — .impeccable/review/. Lighthouse в output/playwright/ относится к предшествующей версии страницы.

Исследование со ссылками и матрицей разделов — docs/research-v2.md; проверка новой версии — docs/verification-v2.md. scripts/browser-qa.js и docs/verification.md относятся к первоначальной v1.
