# ТоргПит

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Статические HTML, CSS и JavaScript. Для просмотра и статической сборки браузерные зависимости не нужны. Sharp используется только при повторной оптимизации изображений.

## Product Purpose

Клиентское демо главной страницы поставщика оборудования для общепита и торговли. Посетитель изучает категории, выбирает оборудование под формат заведения и готовит запрос на подбор.

## Users

Предполагаемая аудитория по содержанию предоставленного референса: владельцы и сотрудники ресторанов, кафе, пекарен и магазинов.

## Capabilities and Constraints

Поиск по категориям, подборка направлений оборудования, FAQ, инженерный чек-лист и бриф с необязательными параметрами проекта. Черновик сохраняется в текущей вкладке. Запрос можно проверить, открыть в почте, скопировать или скачать. Сервер приёма заявок и актуальная товарная база не предоставлены. Демо не заявляет об успешной отправке заявки.

## Brand Commitments

Воспроизвести композицию и язык изображения «Премиальное оборудование для кухни (1).png», включая логотип ТоргПит, порядок разделов, предметные изображения, светлую витрину, тёмные фотосекции и оранжевые действия.

## Evidence on Hand

Пользовательский референс 724 × 2172 пикселя сохранён в корне как первоначальная визуальная основа. По запросу пользователя все изображения заменены 16 самостоятельными генерациями, созданы 33 WebP-версии. Исходники и точные prompts: source-images/. Отраслевое исследование: docs/research-v2.md; исследование анимации: docs/motion-research.md. Новые кейсы, цены и партнёрства не подтверждены и не добавлены.

## Operating Context

Запрошен репозиторий devweb-test/torgpit и публичная демонстрационная ссылка для клиента. На момент начала реализации репозиторий отвечает 404; доступный GitHub-коннектор не содержит операции создания репозитория.
