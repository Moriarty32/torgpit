# Проверка версии v2

## Исследование → исправление

Исходные проблемы и первоисточники: research-v2.md. Заменены фрагменты скриншота 16 отдельными генерациями. Поиск приведён к фактическому охвату категорий; разнородное сравнение заменено подборкой. Выбор категории сохраняет задачу пользователя. Добавлены результат проработки оснащения, инженерный чек-лист и необязательные поля проекта. ## Визуальное качество и доступность

Проверены desktop, phone и intermediate. Отдельно открыты контактный блок, категории и рабочая поверхность. Ни одно изображение интерфейса больше не ссылается на reference.png. Исходные пропорции не растягиваются; используются contain и cover. Для полностраничных скриншотов lazy-изображения декодируются до захвата. Для скриншота области контактов липкая шапка скрыта только в состоянии браузерной съёмки, исходный CSS не менялся.

Контраст выбранных основных пар рассчитан: white/orange 5.53:1, muted/paper 6.20:1, dark-muted/dark 9.39:1. Это не заменяет ручной аудит всей страницы. Мобильные иконные кнопки 44×44px. Улучшены доступные имена категорий, поиск имеет клавиатурные состояния.

Impeccable detector выполнен один раз в ограниченном regex-режиме; отмечены advisory-отличия от документации v1 по цветам, размерам и радиусам. Документация DESIGN.md и sidecar обновлены под реализованную v2. Повторный detector не запускался; его старые замечания не объявляются автоматически устранёнными.

## Ограничения

Демо статическое. Нет сервера обработки заявок, настоящей базы SKU, актуальных цен и наличия. Новые телефоны, адреса, гарантии и партнёрства не подтверждены и не выдуманы. Генеративные иллюстрации не объявлены фотографиями реальных объектов или точными товарными изображениями. Браузерные проверки проведены в Chromium, а не на физических мобильных устройствах.

Отчёты Lighthouse находятся локально в output/playwright/lighthouse-v2.json и lighthouse-v2-final.json. Показатели относятся к лабораторному запуску на localhost с мобильным профилем и не являются полевыми Core Web Vitals. Индексация намеренно закрыта через noindex для клиентского демо.
