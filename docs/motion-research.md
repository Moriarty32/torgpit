# Анимация главной страницы torgpit.ru

Дата исследования: 20 ноября 2026 года.

Статус: исследование применено к реализации. После первого исследования получен референс «Премиальное оборудование для кухни (1).png». Композиция и палитра сохранены; выполнены CSS-появление заголовка и фотографии первого экрана, заливка кнопок, подчёркивание ссылок, движения изображений в карточках, появление диалога и содержимого FAQ. Реализован prefers-reduced-motion. Конкретные эффекты проверены в браузере; частота кадров на физических устройствах не измерялась.

## Вывод

Премиальное ощущение создаёт согласованная реакция интерфейса: точный момент начала, умеренная амплитуда и одинаковая логика возвращения в исходное состояние. Предлагается один выразительный сценарий первого экрана и спокойные состояния остальных элементов. Это проектная рекомендация, а не результат сравнительного пользовательского теста.

## Источники и применение

1. [Google / web.dev: производительные CSS-анимации](https://web.dev/articles/animations-guide). Для перемещения и появления использовать преимущественно transform и opacity; анимации геометрии и перерисовки проверять отдельно. Не назначать will-change всей странице.
2. [Material Design: duration & easing](https://m1.material.io/motion/duration-easing.html). Длительность связывать с расстоянием и масштабом изменения; частые взаимодействия должны оставаться быстрыми. Это прежняя система Material, а не её актуальная спецификация.
3. [Material Design 3: Motion](https://m3.material.io/styles/motion). Актуальная система использует пружины, разделяет пространственные изменения и эффекты. Для этой страницы предлагается собственная сдержанная CSS-кривая без обязательного отскока; внедрение Material-компонентов не требуется.
4. [web.dev: prefers-reduced-motion](https://web.dev/articles/prefers-reduced-motion). Предусмотреть отдельный вариант с меньшим пространственным движением, сохранив понятную обратную связь.
5. [Cuberto: официальный сайт](https://cuberto.com/) и [официальная библиотека mouse-follower](https://github.com/Cuberto/mouse-follower). Рассмотрены как источник выразительных взаимодействий. Собственный курсор и магнитные эффекты не назначены проекту: решение зависит от композиции и назначения референса.
6. [MDN: hover](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/hover). Эффекты наведения включать только для соответствующего устройства; основные действия должны работать касанием.
7. [MDN: Intersection Observer](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API). Использовать для запуска ограниченной анимации при входе в экран и остановки наблюдения после её завершения.
8. [GSAP: common mistakes](https://gsap.com/resources/mistakes/). Если понадобится сложная последовательность, не смешивать конкурирующие владельцы одной анимируемой величины. Подключение GSAP пока не выбрано.

## Предлагаемая система взаимодействий

Все численные значения ниже — отправные параметры для реализации и проверки, а не значения, предписанные источниками.

| Элемент | Наведение / изменение | Нажатие / выход | Начальный бюджет |
| --- | --- | --- | --- |
| Основная кнопка | Заливка проходит внутри неподвижного контура, подпись сохраняет читаемость | Короткое сжатие до 0.985, затем возврат | 220–320 мс; нажатие 100–140 мс |
| Вторичная кнопка | Изменение заливки и контраста рамки | Более быстрый возврат | 160–220 мс |
| Текстовая ссылка | Линия проявляется через scaleX, без изменения размеров строки | Линия уходит по согласованной траектории | 180–240 мс |
| Карточка с фотографией | Изображение увеличивается максимум до 1.025 внутри обрезки | Плавный возврат; соседние элементы неподвижны | 400–550 мс |
| Меню на телефоне | Панель и её содержимое появляются как единое состояние | Ускоренное закрытие и восстановление фокуса | Открытие 250–320 мс; закрытие 180–220 мс |
| Поля формы | Изменение рамки при фокусе, очевидное сообщение ошибки | Состояние результата рядом с формой | 140–180 мс |
| Первый экран | Сценарий определяется предметом референса; максимум одна последовательность | Страница доступна до её завершения | 550–750 мс |
| Последующие блоки | При необходимости одноразовое мягкое появление | Без повторного запуска при прокрутке назад | 350–450 мс |

Базовая кривая прибытия: cubic-bezier(0.22, 1, 0.36, 1). Обычные состояния: cubic-bezier(0.2, 0, 0.2, 1). Проверять быстрые повторные наведения и прерывание анимации.

## Детали реализации

- Контент виден без JavaScript. Появление добавляется как улучшение, а не как условие чтения страницы.
- Обычная прокрутка браузера; якорям задать отступ с учётом шапки.
- Состояния focus-visible проработать отдельно, включая кнопки закрытия и ссылки в меню.
- Hover не должен открывать единственный доступ к содержимому.
- В режиме уменьшенного движения убрать перемещение, масштаб и параллакс; оставить короткую смену цвета и понятные состояния.
- Циклическую декоративную анимацию применять только при ясной связи с референсом и останавливать вне экрана / в скрытой вкладке.
- Шрифты и изображения по возможности хранить в проекте. Задать размеры изображений заранее для устойчивой композиции при загрузке.
- Для клиентского демо формы должны честно описывать результат. Имитация отправки без сервера не должна выдавать себя за принятую заявку.

## План проверки после получения референса

Один совместный проход desktop/mobile: сравнить масштаб и композицию с изображением, проверить переносы, горизонтальный скролл, действия кнопок, меню, клавиатуру, контраст состояний и reduced motion. После исправлений — один подтверждающий проход. Отдельно проверить публичный URL и загрузку ассетов относительно пути GitHub Pages. Результаты производительности записывать только после измерения.
