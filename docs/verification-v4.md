## Первый экран

| Окно | Прежняя нижняя граница hero | Новая нижняя граница |
|---|---:|---:|
| 2560×1440 | 794.6px | 1440px |
| 1920×1080 | 794.6px | 1080px |
| 1366×768 | 788.8px | 768px |
| 1024×768 | 734.7px | 768px |
| 390×844 | 975.5px | 844px |
| 320×740 | 972.4px | 740px |

Контейнер широкого экрана увеличен с 1240 до 1480px. При этом текст сохраняет ограниченную длину строки. Высота последующих разделов определяется содержимым и гибкими отступами.

Проверены 14 размеров: 2560×1440, 1920×1080, 1440×900, 1366×768, 1280×720, 1200×800, 1024×768, 900×600, 768×1024, 724×1000, 390×844, 360×800, 320×740, 844×390. Горизонтального переполнения нет. В очень низком горизонтальном окне содержимое увеличивает высоту hero и остаётся доступным при прокрутке, вместо принудительного обрезания.

На телефоне 320px ширина изображения оборудования увеличена примерно с 47 до 88px. Карточки категорий содержат читаемое название, пояснение и самостоятельное изображение. Параметры и рабочие подписи — от 14px. Бриф выровнен по общему контейнеру.

## Исправления финального ревью

Для планшетов затемнение фотографии продлено до правой границы текста. Фон измерен по фактическому снимку Chromium в областях символов: текст скрывался только на время получения фонового изображения, размеры и положение сохранялись. Пробы брались в девяти точках прямоугольника каждого непустого символа.

Минимальные отношения контраста поясняющего абзаца: 8.53:1 при 724px, 10.01:1 при 768px, 10.64:1 при 1024px. Для текста контурной кнопки — 11.04:1, 12.62:1 и 14.73:1. Это целевая выборочная проверка фона в текущей композиции, а не сертификат контраста всех элементов и состояний.

`display: flow-root` удерживает отступ отзывов внутри белой секции. Геометрический зазор между внешними секциями равен 0px, внутренний отступ 48px сохранён, цвет под ним белый. Содержимое и поведение страницы при этих исправлениях не менялись.

## Снимки и ограничения

Финальное независимое ревью: `disposition: ship` для уточнения существующей визуальной системы. После исправлений повторно проверены фон планшетного hero и единая белая область условий/отзывов. DESIGN.md и его sidecar обновлены по фактически построенной версии.

Основные viewport-снимки — `.impeccable/review/desktop.png`, `mobile.png`, дополнительные размеры — `output/playwright/v4/top-*.png`. Каждый основной раздел снят отдельно в читаемом масштабе. В снимках отдельных секций липкая шапка скрывается только на время захвата, чтобы она не перекрывала содержимое. Снимок всей страницы используется как дополнение для оценки ритма; он не заменяет подробные кадры.

Проверки выполнены в Chromium с эмуляцией размеров. Реальные устройства, остальные браузерные движки и полная проверка со скринридером отдельно не выполнялись. Исходный автоматический дизайн-детектор работал в ограниченном режиме; его срабатывания сопоставлены с визуальной оценкой. Lighthouse прежних версий не объявляется результатом v4.

Исследование и исходные проблемы: [design-audit-v4.md](design-audit-v4.md).
